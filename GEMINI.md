# BlueSpring Water Management (Aabe-Pak) - Project Context & Guidelines

## Overview
A responsive water-supplier administration web application built with React, Vite, Firebase Authentication, and Cloud Firestore. It manages customer accounts, delivery records, bill generation, and payment tracking with real-time updates.

## Tech Stack
- **Frontend**: React 19, Vite 6
- **Styling**: Vanilla CSS (`src/styles.css`)
- **Backend / Services**: Firebase Auth (Email/Password), Cloud Firestore
- **Environment**: Node.js 20+, Windows

## Key Commands
- `npm run dev`: Start local development server with Vite
- `npm run build`: Compile and bundle production assets to `dist/`
- `npm run preview`: Preview the production build locally

## Architecture & Data Model
- **Firestore Collections**:
  - `customers`: Customer profiles, contact details, delivery addresses, and delivery preferences.
  - `bills`: Invoices, billing cycles, balance tracking, and payment history.
- **IDs & Formatting**: Auto-generated by Firestore with readable display prefixes.
- **Sharing & Exporting**:
  - WhatsApp click-to-chat URL integration for sending bills directly to customers.
  - Browser print-friendly layout formatted for PDF export via "Save as PDF".

## Security & Access Control
- Authentication relies on verified email/password accounts. Unverified accounts are blocked by both client checks and security rules.
- Admin allowlist must be kept synchronized across:
  1. `VITE_ADMIN_EMAILS` in `.env`
  2. Allowlist checks in `firestore.rules`
- Never deploy permissive or open Firestore rules; `firestore.rules` is the primary security boundary.

## Development Conventions
- Adhere strictly to existing styling patterns in `src/styles.css` without adding external utility CSS frameworks like Tailwind unless requested.
- Maintain strict type and null checks when interacting with Firestore documents.
- Keep client configuration secure and decouple sensitive admin provisioning from client-side actions.
