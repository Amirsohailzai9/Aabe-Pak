# BlueSpring Water Management

A responsive water-supplier admin app built with React, Firebase Authentication, and Cloud Firestore. Customer and bill records are stored in Firestore and update live for the signed-in admin.

## Run locally

1. Install Node.js 20 or later.
2. Create a Firebase project at [Firebase Console](https://console.firebase.google.com/), add a Web app, and enable **Authentication → Email/Password**.
3. Create the **Cloud Firestore** database.
4. Copy `.env.example` to `.env` and fill in the web app configuration from Firebase Project settings. Set `VITE_ADMIN_EMAILS` to a comma-separated list of admin email addresses. `VITE_CURRENCY` accepts a currency code such as `USD`, `EUR`, or `PKR`.
5. Create the admin account in **Authentication → Users**. Verify the email address before signing in; unverified accounts are rejected by the app and Firestore rules.
6. In `firestore.rules`, replace `admin@example.com` with the exact admin email address(es) used in step 4. Publish the rules from **Firestore → Rules** in the Firebase console. Keep the rules allowlist in sync with `VITE_ADMIN_EMAILS`.
7. Run:

   ```sh
   npm install
   npm run dev
   ```

   Open the local URL printed by Vite.

## Data and access control

Customers are stored in `customers`; bills and payment history are stored in `bills`. Customer and bill IDs are generated by Firestore and displayed with readable prefixes. The client checks the configured admin email list for a friendly login experience; the Firestore rules independently require an authenticated, verified email that is explicitly allowlisted. Never deploy permissive Firestore rules.

The app does not provision admin accounts or grant roles. Add and remove accounts using Firebase Authentication and update the rules allowlist when admin access changes. Treat the Firebase web configuration as public client configuration; Firestore rules are the security boundary.

Bills can be shared using a WhatsApp click-to-chat URL. Printing uses the browser print dialog; choose **Save as PDF** to download a PDF copy.
